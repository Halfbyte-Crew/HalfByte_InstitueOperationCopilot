# UI/UX Specification

## Primary Screens
- Dashboard (alerts: attendance risk, EMI dues, trainer clashes)
- Students and Batches management
- Fees/EMI tracker
- Attendance and recordings
- Copilot chat workspace
- Timetable planner
- Action approvals inbox
- Audit trail viewer

## Copilot UX Principles
- Prompt box with examples (e.g., attendance + EMI follow-up queries)
- Structured answer cards (summary, filters used, confidence/explanation)
- Always show executed read-only query beneath the answer
- Redaction/denial message when role lacks permission

## Action UX Principles
- Explicit preview of changes/messages before execution
- Clear Approve/Reject controls with confirmation
- Visual diff for schedule re-plans and explanation of each change
