# Delivery Phases

## Phase 1: Foundation
- Core data model and CRUD for students/batches/courses/trainers
- Authentication and RBAC
- Basic attendance and fee tracking

## Phase 2: Copilot Read-Only Intelligence
- Natural-language query intake
- Safe read-only query generation and execution
- Query transparency in every response

## Phase 3: Human-in-the-Loop Actions
- Action preview workflows
- Approval queue and execution pipeline
- Full audit logging

## Phase 4: Timetable Optimization
- Constraint-based scheduler
- Rapid re-planning and explanation engine

## Phase 5: Optional Enhancements
- Payment reconciliation
- Certificate generation
- Dropout risk scoring with reasons
