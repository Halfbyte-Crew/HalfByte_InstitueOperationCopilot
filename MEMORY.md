# Project Memory (Initial)

## Problem Context
Institute operations currently depend on disconnected tools and manual coordination, leading to delayed interventions and operational errors.

## Product Intent
Create a central operations platform with an AI copilot that is transparent, role-safe, and approval-driven for all risky actions.

## Non-Negotiables
- Role-based data isolation (especially trainer fee-data restriction)
- Query transparency for every answer
- Human approval before writes/messages
- Complete action auditability

## Planning Note
This memory document captures baseline constraints and goals for future implementation phases.
